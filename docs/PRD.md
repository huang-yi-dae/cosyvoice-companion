# CosyVoice Companion · 产品需求文档（PRD）

> 版本：v1.0 · 状态：现状梳理 + 演进建议
> 定位：**个人研究用途**——从 QQ 聊天记录重建某个人的声音（CosyVoice 克隆 / 云端 TTS）
> 与人设（companion agent），用于陪伴对话。**仅限个人研究、需获对方授权，非商业化。**

---

## 1. 产品概述

### 1.1 一句话定义
把 QQ 里某位好友的语音消息与聊天记录，转化为「可对话、会用他的声音说话」的数字陪伴体。

### 1.2 背景与动机
- QQ 语音消息以 SILK v3 格式散落在本地 NTQQ 数据目录，普通用户无法直接利用。
- 想留住一段关系 / 一个人的声音与说话方式（语气、口头禅、对话习惯）。
- 已有开源能力（CosyVoice 零样本克隆、DashScope 云端 TTS、Qwen LLM）可组合成完整链路，
  但缺少一个**把全流程串起来、且本地可控**的工具。

### 1.3 核心价值主张
| 维度 | 价值 |
|------|------|
| **全流程自动化** | 除「登录 QQ」外，从提取密钥 → 解密 → 导出 → 清洗 → 转码 → 生成人设，一键跑完 |
| **隐私本地化** | 所有隐私数据留在本地 `private/`（gitignore），密钥、聊天、语音均不出本机 |
| **声音可复刻** | 零样本克隆：选几条该好友的语音样本，即可用其音色说任意文字 |
| **人设可对话** | 从聊天记录统计语言风格生成 System Prompt，驱动角色扮演对话 + 克隆语音朗读 |

---

## 2. 目标用户与场景

### 2.1 目标用户
- **唯一用户画像**：项目作者本人（技术能力较强，能在 Windows + PowerShell 下操作）。
- 明确 **非目标**：公开分发、多租户、商业化。

### 2.2 核心使用场景
1. **首次搭建**：登录 QQ → 复制加密库 → 一键跑流水线 → 得到某好友的语音样本 + 人设。
2. **日常合成**：在工作室选样本 + 输入文字 → 得到该好友音色的语音，可保存收藏。
3. **陪伴对话**：在陪伴页与该好友人设对话，回复自动用克隆音色朗读。
4. **多对象管理**：切换不同 QQ 好友，各自独立的样本 / 人设 / 知识库。

## 3. 功能范围（现状）

### 3.1 页面地图
```
┌─────────────────────────────────────────────────────────────┐
│  顶栏（品牌 · 导航 · 当前用户切换）—— 5 页共用                  │
├───────────┬───────────┬───────────┬───────────┬─────────────┤
│  工作室    │  管理台    │  自动化    │  模型      │  陪伴        │
│  /         │  /manage   │  /pipeline │  /models   │  /companion  │
│  合成语音   │  数据管理   │  一键流水线 │  下载管理   │  角色对话     │
└───────────┴───────────┴───────────┴───────────┴─────────────┘
```

### 3.2 各页面职责与关键交互
| 页面 | 核心任务 | 关键 API | 主要交互 |
|------|---------|---------|---------|
| **工作室** `/` | 选音色源 + 文本 → 合成 | `/api/generate`、`/api/voices`、`/api/save` | 提供方切换、样本多选、试听、合成、收藏 |
| **管理台** `/manage` | 管理用户数据 | `/api/users/{qq}/messages`、`/prompt`、`/knowledge-paths` | 用户网格、语音消息列表、Prompt 编辑/重生成、知识库路径 |
| **自动化** `/pipeline` | 一键跑解密→克隆全流程 | `/api/pipeline/start`、`/status` | 步骤勾选、启动、实时状态 + 日志、需人工暂停 |
| **模型** `/models` | 下载 / 管理 CosyVoice 模型 | `/api/models/catalog`、`/download` | 模型卡片、确认弹窗、下载进度 |
| **陪伴** `/companion` | 角色扮演对话 + 朗读 | `/api/chat`、`/api/generate` | 语音源设置、聊天气泡、自动朗读 |

### 3.3 全流程自动化步骤（自动化页）
| # | 步骤 | 自动/人工 | 说明 |
|---|------|----------|------|
| 0 | 登录 QQ + 复制加密库 | **人工** | 唯一的手动前提 |
| 1 | 提取解密密钥 | 自动（需管理员 + QQ 登录） | 读取进程内存中的 SQLCipher 密钥 |
| 2 | 解密数据库 | 自动 | 导出明文 SQLite |
| 3 | 导出聊天记录 | 自动 | → `chat_log.json` |
| 4 | 清洗数据 | 自动 | → `chat_log_clean.json` |
| 5 | 转换语音格式 | 自动 | SILK → WAV |
| 6 | 生成角色 Agent | 自动 | → `SystemPrompt.txt` + 知识库 |

### 3.4 音色提供方
- **本地模型**：CosyVoice-300M 系列，零样本克隆，需参考样本。
- **云端（DashScope）**：阿里云百炼预注册音色，无需本地样本，需 API Key。

## 5. 已完成的体验优化（v2）

| 编号 | 优化项 | 页面 | 价值 |
|------|-------|------|------|
| P1 | 样本试听播放/暂停 + 播放态反馈 | 工作室 | 消除"点了没反应"的困惑 |

## 6. 非功能需求

| 类别 | 要求 |
|------|------|
| **隐私** | 密钥/聊天/语音仅存本地 `private/`；默认仅 `127.0.0.1` 监听；可选 token 鉴权 |
| **安全** | 密钥提取需管理员权限；解密等高危操作应有二次确认与审计（见 ROADMAP #9） |
| **性能** | 模型懒加载；首次合成 ~1 分钟（可选启动预热，见 ROADMAP #18） |
| **平台** | Windows / PowerShell / Python 3.11；前端为现代浏览器 |
| **可维护** | 配置驱动（YAML + .env）；切换分析对象无需改代码 |

## 7. 关键指标（个人项目视角）

由于是个人研究工具，不设商业指标。以「顺畅完成一次完整体验」为北极星：

- **首次搭建成功率**：能否在无外部帮助下跑完流水线（受管理员权限 / QQ 登录 / 加密库路径影响）。
- **合成可用率**：选样本 → 得到满意音色的比例（受样本质量、模型选择影响）。
- **对话沉浸感**：人设 Prompt 是否贴近真实语气 + 语音是否像本人。

## 8. 已知约束与风险

| 风险 | 说明 | 缓解 |
|------|------|------|
| 平台锁定 | 仅 Windows（密钥提取依赖读 QQ 进程） | 明确标注；非目标跨平台 |
| 首次加载慢 | 本地模型加载 ~1 分钟 | P3 计时器提示；ROADMAP #18 预热 |
| 克隆效果不稳 | 样本质量 / 数量影响大 | 多选样本拼接；ROADMAP #17 样本预处理 |
| 隐私敏感 | 涉及他人语音与聊天 | 强约束本地化 + 需授权声明 |
| 云端复刻缺闭环 | DashScope 在线复刻缺 OSS 上传 | ROADMAP #14 |
